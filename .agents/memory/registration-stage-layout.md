The supplied intake mockup is the source of truth for the registration layout. Stage 1 uses four full-height columns: identity, appearance selection, character preview, and prisoner type. Stage 2 remains available as a larger specialization step in the wizard.

**Why:** The latest supplied reference explicitly shows prisoner type beside the appearance and character panels, so visual fidelity takes priority over the earlier staged-flow interpretation.

**How to apply:** When changing the registration layout, preserve the four-column desktop structure for stage 1, fit it at the 1024px reference viewport, and let it collapse into a vertical flow on mobile.
